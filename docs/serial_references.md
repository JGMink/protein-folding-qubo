# Serial solver reading list

Focused sources for this solver; PT papers provide background, not implemented features.
BibTeX is in [serial_references.bib](serial_references.bib).

- [Folding lattice proteins confined on minimal grids using a quantum-inspired encoding (2025)](https://doi.org/10.1103/8n7p-7lh2) — Source model and MJ-48 protocol.
- [Optimization by Simulated Annealing (1983)](https://doi.org/10.1126/science.220.4598.671) — Classical simulated annealing foundation.
- [Exchange Monte Carlo Method and Application to Spin Glass Simulations (1996)](https://doi.org/10.1143/JPSJ.65.1604) — Exchange Monte Carlo foundation; background only.
- [Replica-exchange molecular dynamics method for protein folding (1999)](https://doi.org/10.1016/S0009-2614(99)01123-9) — Protein-folding application of replica exchange.
- [Multiplexed-Replica Exchange Molecular Dynamics Method for Protein Folding Simulation (2003)](https://doi.org/10.1016/S0006-3495(03)74897-8) — Related protein-folding replica-exchange research.
